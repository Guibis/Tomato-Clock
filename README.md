# 🍅 Pomodoro Clock

A minimalist Pomodoro Timer built with **HTML, CSS, and JavaScript**, designed to help developers stay focused and productive without unnecessary complexity.

## 🧠 About the Project

In a world full of distractions, deep focus is a competitive advantage.  
This project is a **single-page Pomodoro Clock** that follows the classic Pomodoro Technique:

- 25 minutes of focused work
- 5 minutes of break
- Visual tracking of completed work sessions
- Manual control over session history

The goal is simplicity, clarity, and efficiency.

---

## ✨ Features

- ⏱️ **25:00 Timer Display** (default work session)
- ▶️ **Start**, ⏸️ **Pause**, and 🔄 **Reset** controls
- 🔁 **Work / Break modes**
- 🍅 **Session History** — a tomato emoji is added for every completed work session
- 🧹 **Clear History Button** — allows the user to reset the session history at any time
- 📱 **Responsive and minimalist UI**

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
